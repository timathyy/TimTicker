# 架构决策记录

本目录记录会长期影响 TimTicker 结构、数据兼容性或交付方式的决定。每份 ADR 一旦标记为“已接受”，后续若要改变，应新增 ADR 说明替代关系，而不是直接改写历史背景。

状态含义：

- **提议中**：方向尚未最终确认，可以继续验证或调整；
- **已接受**：当前开发必须遵循；
- **已取代**：已由更新的 ADR 替代；
- **已废弃**：不再适用且没有直接替代方案。
